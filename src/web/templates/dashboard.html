策略说明
  • 7 个币：BTC / ETH / SOL / XRP / DOGE / BNB / HYPE，各有 15m 与 5m 两套尾盘策略。 推荐参数来自 docs 目录中的稳健版回测；XRP 暂无独立文档，先用保守通用参数。
  • 默认只启用 BTC 15m / 5m，其余在「参数」页按币种开启。全部默认纸面 10 USDC； 实盘单笔默认 5 USDC，切换模式后生效。
  • 15m 参数通常更稳；5m 对滑点和流动性更敏感，BNB / HYPE / DOGE 的尾部流动性尤其薄， 建议先用纸面观察成交率。
  • 所有策略共享一个钱包，但风控（日亏损、连亏、暂停）按「币种 + 周期」独立计算， 纸面与实盘也互不影响。
